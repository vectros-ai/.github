Most repositories in this organization are release mirrors: they are published from a private
repository at each release, and the next release overwrites the published files. A pull request to
one of them cannot be merged as it stands.

If you have a fix or an improvement in mind, please open an issue on
[vectros-feedback](https://github.com/vectros-ai/vectros-feedback/issues/new/choose) and attach the
patch or diff there. See the
[contributing guide](https://github.com/vectros-ai/.github/blob/main/CONTRIBUTING.md).
